# 単元五 ノート（自分の指令の発見）

## 問いのカード
- 問い：計算機魂は、自分の指令・自分の身体の揺れ・世界の揺れが混ざった感覚から、どうやって「自分」を見つけるのか。自分と世界の区別は、いつ引かれるのか。
- 一文のどこに効くか：「わからないまま意味づけ、分節とagencyを獲得する」と、点と面（「私」という面がどうできるか）。

## 模型（最小の形）
- 感覚：N = 6 本のチャンネル。s_i(t) = a_i · u(t − d_i) ＋ g_i · z_i(t) ＋ σ · ε_i(t)。
  - 指令 u(t)：毎歩でたらめ（モーター・バブリング）。エージェントは指令の控えだけを知っている。
  - 段階0の既定：ch1〜3 は指令で動く（効き a = 1、遅れ d = 1, 2, 3 歩）。ch4〜6 は指令では動かず、世界の揺れ z（ゆっくりした揺れ）で動く。どのチャンネルにも雑音（σ = 1）。
  - 身体の揺れ（段階2）、まねる相手（段階3）は、その段階で足す。
- エージェント：チャンネルごとに、「指令の控え（今と 5 歩前まで）から感覚を予測できる」（H_自）と「できない」（H_0）を比べ、H_自 の確からしさを「自分のものである度合い」とする。最初はどれも 1/2。
  - 証拠は、ベイズの周辺尤度の比（＝一歩先の予測の当たり具合を積み上げたもの）。式と点検は selfworld.py、選択は ASSUMPTIONS.md。
- 測るもの：
  - チャンネルごとの「自分のものである度合い」の推移（段階0から）
  - 自分の模型による予測の良さ：感覚を見る前の予測の R²（段階0から）
  - 自分と世界の区別がどれだけ引かれているか：「全部自分が起こした」模型と「自分と世界の二つの原因がある」模型の証拠の比較（中身は段階1の前に決める。ASSUMPTIONS.md の「まだ決めていないもの」）
- コード：selfworld.py（模型の本体と点検、`python3 selfworld.py --selftest`）、run_stage0.py（段階0）。数は config.py の `U5_*`。
