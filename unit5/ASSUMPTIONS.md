# 論文外の仮定

単元五の模型は、一つの論文の再現ではない。委任書の「模型（最小の形）」に書かれていない選択と、各段階のあとで読む論文（Stoytchev 2011 など）に書かれていない選択を、すべてここに書く。
「決めたもの」は今のコードに入っているもの。「まだ決めていないもの」は、その段階で予想を伺ったあとに決めて書き足す。数はすべて config.py の `U5_*` にある。

## 決めたもの（段階0）

### 感覚を作る側（エージェントには見えない）
1. **時間**：離散（一歩ずつ）。
2. **指令**：一本（一次元）。毎歩、独立な正規分布 N(0, 1)（`U5_COMMAND_SD`）。これを「でたらめな指令（モーター・バブリング）」とする。始まる前（t < 0）の指令は 0。
3. **指令の効き**：チャンネル i に a_i · u(t − d_i)。一つの遅れ d_i だけに、線形に効く（`U5_SELF_GAINS`、`U5_SELF_DELAYS`）。段階0の既定は ch1〜3 が a = 1、d = 1, 2, 3 歩。ch4〜6 は a = 0。
4. **世界の揺れ**：チャンネルごとに独立な AR(1)：z(t+1) = ρ z(t) + √(1 − ρ²) ξ(t)、分散 1、ρ = 0.95（`U5_WORLD_RHO`、相関の続く時間はおよそ 1/(1 − ρ) = 20 歩）。定常な状態から始める。効き g_i（`U5_WORLD_GAINS`）は、段階0では ch4〜6 だけ 1。自分のチャンネルには足さない（体は指令で動き、ほかの物は勝手に動く、という場面にそろえた）。
5. **雑音**：独立な標準正規分布 × σ（`U5_NOISE_SD`、どのチャンネルも同じ、既定 1）。時間の規則性もチャンネルどうしの関係もない。
6. **乱数**：numpy の `default_rng`（PCG64）、種は config。多数の走行を配列でまとめて進める（走行どうしは独立）。

### エージェント
7. **小さな線形の模型**：指令の控え U(t) = (u(t), u(t−1), …, u(t−L))、L = 5（`U5_LAGS`）から、チャンネルごとに s_i(t) ≈ w_i · U(t) と予測する。エージェントは遅れを知らないので、窓の中のどの遅れにも同じ事前分布を置く。**窓の外（6 歩以上）の遅れは、この模型では表せない。** 定数項は置かない（感覚の平均は 0 とみなす）。
8. **二つの見方**：H_自（s_i(t) = w_i · U(t) ＋ 残り）と H_0（s_i(t) = 残り）。どちらも、残りを平均 0・分散 σ_e²（未知）の独立な正規分布とみなす（世界の揺れには時間の相関があるが、エージェントの模型はそれを持たない）。
9. **事前分布と証拠**：w_i | σ_e² ~ N(0, σ_e² τ² I)、τ² = 1（`U5_TAU2`。重みの大きさを残りの大きさの単位で測る）。σ_e² にはジェフリーズの事前分布（∝ 1/σ_e²）。σ_e² は二つの見方に共通なので、証拠の比（ベイズ因子）は定まり、十分統計量から閉じた式で出る（selfworld.py の冒頭）。周辺尤度は一歩先の予測確率の積なので、この証拠は「予測の当たり具合の積み上げ」でもある。
10. **自分のものである度合い**：H_自 の事後確率。事前は 1/2（`U5_PRIOR_SELF`、委任書の「五分五分」）。チャンネルごとに独立に判断し、チャンネルどうしの関係は使わない。
11. **一歩の順番**：指令を出す → 感覚を見る前に、今までの感覚から度合いと重みを求めて予測する → 感覚を見て十分統計量に足す。忘れることはない（すべての過去を同じ重みで数える）。
12. **予測の良さ**：自分の模型の予測 ŝ_i(t) = 度合い × (重みの事後平均) · U(t)（H_0 は 0 を予測するので、二つの見方を度合いで混ぜた予測）。感覚を見る前の予測で、R² = 1 − Σ(s − ŝ)² / Σ s² を対数等間隔の時間の区切り（`U5_S0_R2_BINS`）ごとに測る。

### 段階0の測り方
13. **「見分けた」の基準**：自分のチャンネル（a_i ≠ 0）は度合い ≥ 0.99、そうでないチャンネルは ≤ 0.01（`U5_DECIDE`）。数えるのは「初めてそうなった歩数」と「そのあと T まで保たれるようになった歩数」。0.99 は論文にない選択。T までに保たれなかったチャンネルは「T より大きい」として四分位に入れる。
14. **長さ・本数・掃引**：一本の走行 10⁴ 歩。掃引一（雑音 σ = 0.1, 0.3, 1, 3, 10）は各 200 本 × 10⁵ 歩。掃引二（遅れ d = 0〜8、三本の自分のチャンネルを同じ遅れにする、σ = 1）は各 200 本 × 10⁴ 歩。

## まだ決めていないもの

- （段階1の前に決める）**「全部自分が起こした」とみなす模型と、「自分と世界の二つの原因がある」とみなす模型の中身**。とくに、雑音（チャンネルごとにばらばらで、時間の規則性もない揺れ）を「世界」に数えるかどうか。
- （段階2で利用者と問答で決める）指令で説明できない残りから推定した隠れた原因を、「身体」とみなすか「世界」とみなすかの規則。身体の揺れの形（周期、指令への連動の仕方）。
- （段階3で決める）まねる相手の作り方（何をまねるか、雑音、効き）。
