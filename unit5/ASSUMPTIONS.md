# 論文外の仮定

単元五の模型は、一つの論文の模型をそのまま作ったものではない（委任書の「模型（最小の形）」を、こちらで具体化したもの）。
委任書と論文に書かれていない選択を、すべてここに書く。数は config.py の `U5_*`。
「決めたもの」は今のコードに入っているもの。「まだ決めていないもの」は、その段階で予想を伺ったあとに決めて書き足す。

## 記号

| 記号 | 意味 | config |
|---|---|---|
| t | 時刻（一歩ずつ。単位はステップ） | |
| N | 感覚のチャンネルの数 | `U5_N_CH` |
| u(t) | 指令（でたらめ） | `U5_U_STD` |
| d_i | チャンネル i への指令の効果の遅れ | `U5_SELF_DELAYS` |
| g | 指令の効果の大きさ | `U5_SELF_GAIN` |
| w_i(t) | 世界の揺れ（分散 1 の OU 過程） | `U5_WORLD_TAU` |
| c | 世界の揺れの効果の大きさ | `U5_WORLD_AMP` |
| σ | 毎回独立な雑音の標準偏差 | `U5_NOISE_STD` |
| L | エージェントが指令の控えを見る窓（遅れ 0〜L） | `U5_LAGS` |
| θ_i | エージェントの順モデル（「自分」の模型）の係数（L + 1 個） | `U5_THETA_PRIOR_VAR` |
| φ_i | エージェントの「世界」の模型の記憶（一歩の相関） | `U5_PHI_GRID_N` |
| v_i | エージェントが指令で説明できない揺れの大きさ（分散） | `U5_LOG10_VAR_PRIOR_*` |
| M1, M2 | 「自分だけ」の模型、「自分と世界」の模型 | `U5_PRIOR_TWO` |

## 決めたもの（段階0）

### 世界（感覚の生成）

1. **時間**：離散（一歩ずつ）。s_i(t) = g u(t − d_i)［自分のチャンネルだけ］ + c w_i(t) + σ ε_i(t)。
2. **指令**：一本（スカラー）で、毎回独立な正規分布 N(0, 1)。滑らかなでたらめ（時間的に相関のある指令）や、何本もの指令は、まだ扱わない。
3. **指令の効果**：線形で、遅れ d_i の一点だけに大きさ g = 1 で現れる（なまった効果や非線形の効果は扱わない）。段階0の主な条件では、ch0〜2 が自分のチャンネル（遅れ 0, 2, 4）、ch3〜5 には指令の効果が届かない。
4. **世界の揺れ**：チャンネルごとに独立な OU 過程。離散化は w(t+1) = a w(t) + √(1 − a²) ξ(t)、a = exp(−1/τ)、τ = 10 ステップ、分散 1（定常分布から始める）。どのチャンネルにも同じ大きさ c で足す（自分のチャンネルにも足す）。チャンネルどうしで共通の「世界の原因」は置かない（一つの世界が多くのチャンネルを同時に揺らす場合は扱わない）。
5. **雑音**：毎回独立な N(0, σ²)。どのチャンネルも同じ σ。
6. **乱数**：numpy の `default_rng`（PCG64）。走行は `U5_CHUNK` = 25 本ずつのかたまりに分け、かたまりごとに `SeedSequence(種).spawn` で別の種を使う。掃引の条件ごとの種は `U5_S0_SWEEP_SEED × 1000 + 10 × (遅れの番号) + (雑音の番号)`。

### エージェント

7. **知っているもの**：自分の指令の控え u(t), u(t−1), ... と、感覚 s(t)。世界の揺れや雑音の大きさ、遅れ、どのチャンネルが自分のものかは知らない。
8. **順モデル（「自分」の模型、チャンネル i）**：s_i(t) = θ_i・ũ(t) + （残り）、ũ(t) = (u(t), ..., u(t − L))、L = 6。遅れ 0〜6 のどれにでも、どんな形の効果にでも合わせられる線形の模型（係数 7 個）。係数の事前は θ_i ~ N(0, θ0 I)、θ0 = 1 で、雑音の大きさとは独立（雑音が小さいときに係数の事前まで狭くなる「共役事前」は使わない）。**窓の外（遅れ 7 以上）の効果は、この模型では表せない。** この θ_i・ũ(t) が、委任書（2026-11-04）の言う「一階の自己モデル（順モデル）」である。コードでは「外から見た自己モデル」（outside_self_model）と名前を分ける（この単元には後者は出てこない）。
9. **「自分でない」の模型**：θ_i = 0。
10. **残り（指令で説明できない部分）の模型**：x_i(t) = φ_i x_i(t−1) + η_i(t)、η_i ~ N(0, v_i)。
    - M1「自分だけ」：φ_i = 0。残りは毎回独立（「原因」は自分だけで、残りはただの雑音）。
    - M2「自分と世界」：φ_i は (0, 1) の上で一様。残りに記憶がある（もう一つの原因が続いて効いている）。
    - **エージェントの「世界」は、この「残りの記憶」のことである。** 真の世界は OU ＋ 毎回独立な雑音（ARMA(1,1) の形）なので、エージェントの世界の模型（雑音を別に持たない一次の自己回帰）は近似である。負の φ（ぎざぎざの揺れ）は考えない。
    - M2 は φ_i → 0 の極限で M1 と同じ形になる（M1 は M2 の端の一点）。
11. **残りの大きさ v_i**：log10 v ~ N(0, 2²)（桁で ±2 が一標準偏差）。チャンネルごと、仮説ごとに別々に推定する。
12. **事前の重み**：各チャンネルが自分の指令で動く確率 ½（委任書のとおり）。M1 と M2 は ½ ずつ。チャンネルどうしは、M1／M2 のどちらかを共有する以外は独立。
13. **尤度の取り方**：最初の観測 s(−1) と、窓に要る過去の指令を与えたときの条件つきの尤度。どの仮説も同じ観測 s(0), ..., s(n−1) を使う。φ のある仮説は y(t) = s(t) − φ s(t−1)、X(t) = ũ(t) − φ ũ(t−1) に変換すると線形回帰になる（ヤコビアンは 1）。
14. **積分の仕方**：
    - θ_i：ガウスの式で厳密に積分（N(y; 0, v I + θ0 X Xᵀ)）。
    - φ_i：(0, 1) を 50 等分した区間の中点（0.01, 0.03, ..., 0.99）の平均。
    - v_i：x = ln v のまわりのラプラス近似。山の頂上はニュートン法（15 回）で探す。出発点は二つ（最小二乗の残りから／全体の分散から）で、別々の山に着いたら二つを足す。点検（selftest）：細かい格子での数値積分との差は、n = 5 で 0.2 程度、n ≥ 10 で 0.03 未満、n ≥ 30 で 0.01 未満（対数の証拠）。
    - 証拠は、各時刻で、それまでの全データから計算し直す（前の時刻の誤差は持ち越されない）。
15. **θ の事後平均**（予測の良さに使う）：v はラプラス近似の頂上 v* に置き、φ は事後の重みで混ぜる。「自分でない」の場合の θ = 0 も、P(自分) の重みで混ぜる。

### 測るもの

16. **自分のものである度合い**：P(チャンネル i が自分の指令で動く | データ) = Σ_M P(M | データ) P(自分 | データ, M)。
17. **自分と世界の区別**：log BF = ln p(データ | M2) − ln p(データ | M1)（自然対数）。ここで p(データ | M) = Π_i [½ p(s_i | 自分, M) + ½ p(s_i | 自分でない, M)]。正なら「世界という第二の原因がある」を支持し、負なら「全部自分（と雑音）」を支持する。P(M2 | データ) = 1/(1 + e^(−log BF))（事前 ½ のとき）。
18. **順モデルによる予測の良さ**：R²_i = 1 − E[(s_i − θ̂_i・ũ)²] / Var(s_i)。期待値は真の分布（実験者の目）でとる。指令は毎回独立なので E[(s_i − θ̂_i・ũ)²] = |θ̂_i − θ_i|² + （窓の外の係数）² + c² + σ²。上限は、窓の中の自分の効果が分散に占める割合（ch0〜2 で g²/(g² + c² + σ²)、世界だけのチャンネルで 0）。
19. **見分けた時刻**：記録の時刻のうち、そこから最後（T）まで、自分のチャンネルなら P ≥ 0.95、世界だけのチャンネルなら P ≤ 0.05 にとどまり続ける最初の時刻。とどまらなければ「T までに見分けられなかった」とし、中央値や四分位では ∞ として数える（四分位は補間しない）。
20. **記録の時刻**：n = 1〜50 は毎ステップ、その先は T まで対数等間隔に 120 点（重なりを除いて 169 点）。

### 段階0の値

21. **主な条件**：上の 3〜5 の世界（c = 1、τ = 10、σ = 0.5）、200 本 × 2000 ステップ（種 `U5_S0_SEED`）。
22. **掃引**：三本の自分のチャンネルをすべて同じ遅れ d ∈ {0, 1, 2, 4, 6, 7, 8, 12} にし、雑音 σ ∈ {0.1, 0.5, 1, 2} と組み合わせる（32 条件）。各 100 本 × 2000 ステップ（種 `U5_S0_SWEEP_SEED`）。c = 1、τ = 10 は主な条件と同じ。
