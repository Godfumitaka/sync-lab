# 論文の規則とコードの対応

単元五の模型は一つの論文の模型の再現ではないので、二つの表に分ける。

1. **模型の部品とコード**：委任書の「模型（最小の形）」の各部品が、コードのどこにあるか。
2. **論文とコード**：各段階のあとで論文を読んでから書き足す（段階0は Stoytchev (2011)、段階1は Hafner et al. (2020) と Legaspi & Toyoizumi (2019)）。論文に書かれていることだけを書き、推測は混ぜない。

コード：`unit5/selfworld.py`、数は `config.py` の `U5_*`。

## 1. 模型の部品とコード

| 委任書の部品 | コード |
|---|---|
| 感覚：N 本のチャンネル | `simulate` の返り値 `s`（`U5_N_CH`） |
| 自分の指令の効果（一部のチャンネルだけ、遅れつき） | `simulate` の `s[:, :, ch] += gain * u[:, pad + times - d]`（`U5_SELF_CH`、`U5_SELF_DELAYS`、`U5_SELF_GAIN`） |
| 世界の揺れ（時間的に相関のある揺れ、OU 過程） | `simulate` の `w[:, t + 1] = a * w[:, t] + b * xi[:, t]`、a = exp(−1/τ)（`U5_WORLD_TAU`、`U5_WORLD_AMP`） |
| 毎回独立な雑音 | `simulate` の `noise`（`U5_NOISE_STD`） |
| 指令：でたらめに出す（モーター・バブリング） | `simulate` の `u = rng.normal(...)`（`U5_U_STD`） |
| エージェントが知っているのは自分の指令の控えだけ | `Agent.features` が使うのは `u` と `s` だけ（世界と雑音の項、遅れ、どのチャンネルが自分かは渡さない） |
| 最初は「自分の指令で動いている」かどうかを五分五分 | `U5_PRIOR_SELF = 0.5`、`Agent.beliefs` |
| 指令の控えから感覚を予測する小さな線形の模型を学ぶ | 窓 L の線形の模型 θ_i・ũ(t)。`Agent._spectral`（θ を積分）、θ の事後平均は `Agent._evaluate_batch` の `theta1`, `theta2` |
| チャンネルごとに「自分のものである度合い」を更新する | `Agent.beliefs` の `p_self`（各記録の時刻で、それまでの全データから計算） |
| 自分と世界の区別（「全部自分」の模型と「自分と世界」の模型の証拠の比較） | `Agent.beliefs` の `log_bf`、`p_two`（定義は ASSUMPTIONS.md の 17） |
| 自分の模型による予測の良さ | `prediction_r2`（定義は ASSUMPTIONS.md の 18） |

## 点検（`python3 selfworld.py --selftest`）

| 何を確かめるか | どう確かめるか |
|---|---|
| 感覚 = 指令の効果 + 世界 + 雑音 | 生成した項を引き算して、指令の効果だけが残ることを確かめる |
| 世界の揺れが分散 1、一歩の相関 exp(−1/τ) | 50 本 × 4000 ステップの標本で |
| 十分統計量から書いた対数尤度 | 直接の多変量正規の対数密度と比べる（φ = 0, 0.3, 0.9、v を三通り） |
| ln v についての微分 | 差分と比べる |
| v の積分（ラプラス近似） | 40001 点の格子での数値積分と比べる |
| 証拠 = 一歩先の予測の当たりの積（逐次の見方） | v を固定したとき、n 個の証拠と n−1 個の証拠の差が、n 番目の一歩先の予測の対数密度に一致することを確かめる（v を積分した証拠では、ラプラス近似の分だけずれる） |
| θ の事後平均 | (XᵀX + v*/θ0 I)⁻¹ Xᵀy と比べる |
| 確率が [0, 1]、P(自分) が M1 と M2 のあいだ、ニュートン法の収束 | 短い走行で |
| 見分けた時刻の定義 | 手で作った列で |

`--selftest` は式と実装の点検だけを行い、見分けるまでの時間などの結果の統計は出さない。
