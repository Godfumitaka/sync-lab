# 単元三 ノート（二つの振動子）

位相の差 φ = θ₁ − θ₂ は φ̇ = Δω − a sin φ に従う（単元一と同じ式）。双方向では a = 2K、一方向（影）では a = K。

## この単元の意味（迷ったら読む）
- 位置づけ：情報が満ちた極限の基準（互いが相手の位相を正確に知っている）。
- 相手との協調（双方向）と影との協調（一方向）の違いを、式一本で比べる。双方向は a = 2K、一方向は a = K。
- そろう＝協調、滑る＝協調の崩れ、また谷に落ちる＝修復。双方向の方が、そろう範囲が広く、雑音で崩れにくい（相互性が協調を安定させる、のいちばん単純な版）。

## 予想
- （問い一）雑音があるとき、双方向（相手）のほうが一方向（影）より滑る頻度は低い（a が大きいから。どのくらい違うかはまだ）。
- （問い二）そろうと位相の差は一定になってロックされる。双方向でも同じか？（そろったときの二人の速さは、まだ）
- （問い二の続き）そろったときの速さは Δω になる？
- （問い一の続き）頻度は exp(ΔV/D) で決まる。ΔV は f を V の一回微分とみて（f = −dV/dφ）求める。
- （問い二の続き・確認）そろった速さは、双方向で (ω₁ + ω₂)/2、一方向で ω₂（予想の Δω は取り違え）。
- （問い一の続き・確認）φ に入る雑音は 2D（独立な雑音の分散が足し合わさる。双方向でも一方向でも同じ）。滑る頻度の比（双方向 ÷ 一方向）≈ exp(−(ΔV_双 − ΔV_一)/(2D))、ΔV = 2Δω(tan ψ − ψ)、cos ψ = Δω/a。

## 観察
- （play_pair）K = 0.25 で、相手（上）は Δω ≈ 0.5 まで、影（下）は Δω ≈ 0.26 までそろう（2K と K）。
- （同）雑音ありで「上の方がよく滑る（追い越す）」ように見えた。こちらの確かめ（Δω = 0.2、時間 1000）では滑りの回数は 相手 0 / 影 4（D = 1e-2）、0 / 10（D = 10^−1.5）、6 / 25（D = 0.1）。上の段は二点が近く（φ ≈ 0.41）、雑音で前後が入れ替わるのが「追い越し」に見えた可能性。滑り＝φ が 2π 進む＝一周ぶん追い越す。
- （measure_pair、Δω = 0.2、K = 0.25）ln(平均時間) と 1/D の傾きは、相手 0.218〜0.221（予想 ΔV/2 = 0.226）、影 0.0226〜0.0230（予想 0.0213）。平均時間は D = 0.05 で相手 1348／影 68、D = 0.2 で 52／33（差は D が小さいほど指数関数的に開く）。
