# 単元一 ノート

## 予想
- （段階一の前に導いたこと）a > ω で固定点が生まれ、安定性は f のグラフが 0 を横切る向きで決まる。a = ω では半安定な点になる。
- （同）a → ω⁻ で一周の時間 T は (ω − a)^(−1/2) で発散する。遅くなる区間の幅 ∝ √ε、そこでの速さ ∝ ε（ε = ω − a）。
- （実験一の前）雑音なしで a を 1 に近づけると、点は一周のほとんどの時間を θ = π/2 のあたりで過ごす。
- （同）π/2 のあたりを抜けて一周を回り切る部分（階段の蹴上げ）にかかる時間も、(ω − a)^(−1/2) に比例して大きく伸びる。
- （同・言い直し）蹴上げは伸びない。3π/2 での速さは ω + a で a → ω でもほとんど変わらず、√ε の幅・ε の速さは π/2 のそばだけの話だから。伸びるのは踏み面だけ。
- （実験二の前）雑音なしで a = 0.999 と 1.001 を window 100 で見比べても区別はつかない。違いは π/2 のそばから離れるかどうかで、見分けるには踏み面より長く見る必要がある。
- （実験三の前）a を ω の少し上に置き、雑音がほどよい大きさだと、踏み面に留まっていた点が時折スルッと山を越える。
- （同）後ろ向きの段は、慣性がないので少し戻されてもまた前に進みそう。現れるとしても雑音がとても大きいときくらい（自信はない）。
- （実験四の前）dt を大きくすると一回の雑音の寄与が大きくなり、山を越えやすくなりそう。
- （同・言い直し）後ろに一段戻るには、かなり大きな雑音がいる。
- （同・言い直し）一ステップの雑音は √dt、ドリフトは dt に比例するので、dt を大きくすると雑音とドリフトの比が小さくなり、山を越えにくくなる。
- （同・言い直し二）安定点と不安定点のあいだは f ≈ 0 で雑音が主なので、dt を大きくすると越えるのに要るステップ数が減る。
- （実験三の前）滑るときは、3π/2 のあたりを速く回る。
- （実験四の前・言い直し三）安定点と不安定点の距離は短い（π ではない）。dt が大きいと一ステップで不安定点を越えることがあり、振る舞いが変わる。
- （実験四の前・まとめ）D = 1e-2 で dt を 1e-3 から 0.5 に変えても、滑りの頻度はほとんど変わらない（変わっていても見てわからない程度）。
- （段階三の前・問い一）a = ω + δ の壁の高さ：谷と山を π/2 ∓ φ（cos φ = ω/a）と書くと ΔV = 2ω(tan φ − φ) ≈ (2/3)ωφ³。φ ∝ δ^(1/2) より ΔV ∝ δ^(3/2)。
- （段階三の前・問い二）谷の中はほぼボルツマン分布 exp(−V/D) なので、頂上にいる割合は exp(−ΔV/D)。滑るまでの平均時間 ∝ exp(ΔV/D)。

## 観察
- （実験一・二）play.py で確かめた。a = 0.999（いずれ越える）と 1.001（越えない）は、短い窓のあいだは同じ振る舞いに見える。
- （実験一・二のあと）a を知れば区別できるのに、振る舞いを有限時間見るだけでは区別できない。停止問題と似ているが違う。その違いは本質的に何か（問いとして残す）。
- （実験三）a = 1.05 で雑音を入れると、踏み面の長さはバラバラになった（雑音なしの 0.999 の規則的な階段と違う）。後ろ向きの段は出なかった。
- （実験四）dt を変えても、見た目の滑りの頻度はあまり変わらなかった。
- （段階二）ε = 1e-4〜1e-1 の 13 点で、log T の log ε に対する傾きは −0.4974（全点）、−0.4998（ε の小さい半分）。dt = 0.1, 0.01, 0.001 で同じ（T の相対差は最大 1.8e-4）。
- （段階二のあと）全点の傾きが −1/2 から少しずれるのは、x = 0 のそばの近似（cos の展開、次は x⁴/24）が ε の大きい側で怪しくなるから。T√ε の −1/2 の線からのずれは ε = 0.1 で 2.6%、0.01 で 0.25%、0.001 で 0.02%：ずれは ε に比例して縮む。
- （段階二のあと）遅い区間の時間 ∫dx/(ε + x²/2)（範囲は ±∞ に広げる）を x = √(2ε)u で解くと π√2 / √ε ≈ 4.4429 / √ε。測った T√ε = 4.4430（ε = 1e-4）と合う。範囲を広げてよいのは、遠くの寄与が ε によらない有限の量で、ε^(−1/2) の主要部に比べて小さいから。
