# 単元一の付録 ノート（分布と力学）

## 予想
- （手順一）長く回したときの θ の分布（最初はロック側と滑り側を取り違えて答えた。以下は入れ替えたもの）。
- ロック側（a = 1.05）：θ は [0, π/2] の外にはほとんどおらず、π/2 の手前に山が一つ。
- 滑り側（a = 0.95）：sin のような形で山は一つ。雑音なしなら p(θ) ∝ 1/f(θ) で、π/2 の左右で対称、3π/2 でも小さいが 0 ではない。
- D を大きくすると、どちらもなだらかになり（π/2 にたまった確率が雪崩のように広がる）、D → ∞ では一様。二回微分（空間を均す力）と関係していそう。
- （手順一・FP）定常では J は θ によらない定数：f·p − D·dp/dθ = J。円の上では J は 0 とは限らない。
- （同）J と積分定数は、周期境界条件 p(0) = p(2π) と正規化 ∫p dθ = 1 で決まる。J の符号は滑り側で正、ロック側でも正だが小さい。
